# AI Chat Exporter Browser Extension

A lightweight, privacy-focused browser extension for **Chrome** and **Brave** that exports your chat conversations from popular AI chat platforms into cleanly formatted **Markdown (.md)** or **JSON (.json)** files.

This extension runs purely client-side using Chrome's `activeTab` permissions, executing extraction logic only when you request an export. It completely replaces the floating Tampermonkey page overlay with a clean, modern, dark glassmorphic popup dashboard in the browser toolbar.

---

## Acknowledgment

This extension is heavily inspired by and adapted from the original [revivalstack/ai-chat-exporter](https://github.com/revivalstack/ai-chat-exporter) Tampermonkey script by RevivalStack. The browser extension preserves and refactors the original DOM matching, selector structures, and Turndown rule logic inside a native Manifest V3 extension wrapper.

---

## Features

- **Multi-Platform Support**: Works seamlessly on:
  - **ChatGPT** (`chatgpt.com`, `chat.openai.com`)
  - **Claude** (`claude.ai`)
  - **Microsoft Copilot** (`www.copilot.com`, `copilot.microsoft.com`)
  - **Google Gemini** (`gemini.google.com`)
  - **Grok** (`grok.com`)
- **Elegantly Formatted Markdown**: Exports include:
  - **YAML Front Matter**: Stores chat metadata (title, platform author, date, message count, and source URL).
  - **Table of Contents (TOC)**: Autogenerated checklist linking directly to each user question/AI response turn.
  - **Elements Styling**: Clean translation of paragraphs, lists, code fences, headers, inline code, strikethroughs, bold/italic markup, tables, subscripts, and superscripts.
- **JSON Export**: Exports conversations as a structured JSON object.
- **Customizable Filename Formats**: Configure templates in settings using placeholders like `{platform}`, `{title}`, `{timestampLocal}`, `{tags}`, or individual tags (`{tag1}`-`{tag9}`).
- **Gemini Title Customization**: Automatically strips title prefixes (like checkmarks `✓`) from Gemini chats for cleaner filenames.

## Installation (Local Development)

Since this extension is for personal use, you can load it directly into your browser:

1. Open **Chrome** or **Brave** and navigate to `chrome://extensions/` (or `brave://extensions/`).
2. Toggle on the **Developer mode** switch in the top-right corner.
3. Click the **Load unpacked** button in the top-left corner.
4. Select the directory containing this extension (e.g., `~/projects/utility-scripts/ai-chat-export` or the folder containing `manifest.json`).
5. Open your extensions list (the puzzle piece icon in the browser toolbar) and pin **AI Chat Exporter** to your menu bar.

---

## How to Use

1. Navigate to a chat conversation page on any supported platform (e.g., ChatGPT, Gemini, Claude, Grok, or Copilot).
2. Click the **AI Chat Exporter** icon in your browser toolbar. The status card will glow indicating the active platform.
3. Click **Export as Markdown** (or **Export as JSON**). The download will execute and save directly to your default downloads folder.
4. Access the **Settings** gear to customize the filename template or change the Gemini title prefix.
